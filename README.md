# Sanbuk API Spec

The single source of truth for the Sanbuk public API.

All official SDKs are generated from the OpenAPI document in this repository.
Changes to the API surface start here.

## Planned contents

- `openapi.yaml` — full API description
- `events/` — conversion event schemas (action types, `event_id` contract, dedup rules)
- `postback/` — server-to-server postback specification
- `examples/` — request and response samples
